# 食品工場DX フロントエンド

Spring Boot(バックエンド、`http://localhost:8080`)とは別リポジトリ・別プロジェクトとして運用する。

## 含まれるもの

```
index.html                  HTMLのエントリーポイント(BootstrapをCDNで読み込む)
vite.config.js               Viteの設定
package.json                 依存関係
src/
  main.jsx                   Reactの起動地点
  App.jsx                    全体レイアウト(現時点ではMaterialsPageのみ)
  api/client.js              バックエンドとの通信をまとめた共通処理
  pages/MaterialsPage.jsx    材料マスタ画面(一覧+登録フォーム)
```

## セットアップ手順

### 1. Node.jsのインストール確認

```
node -v
```

インストールされていない場合は、公式サイト(https://nodejs.org/)からLTS版をインストールする。

### 2. 依存関係のインストール

このフォルダ(`package.json`がある場所)で以下を実行する。

```
npm install
```

初回は`node_modules`フォルダが作られ、少し時間がかかる。

### 3. 開発サーバーの起動

```
npm run dev
```

成功すると、`http://localhost:5173`のようなURLが表示されるので、ブラウザでアクセスする。

### 4. バックエンドも同時に起動しておくこと

このフロントエンドは`http://localhost:8080/api/...`にAPIリクエストを送る作りになっているため、
**Eclipse側でSpring Bootアプリ(`DxApplication`)も同時に起動しておく必要がある**。

## 【重要】バックエンド側にCORS設定の追加が必要

ブラウザは仕様上、「動いているポート(5173)と違うポート(8080)への通信」を
デフォルトでは拒否する(CORSエラーというもの)。そのため、バックエンド側に
「5173番からのアクセスを許可する」という設定を追加する必要がある。
これは別途、バックエンド側のファイルとして提供する(`WebConfig.java`)。

## 動作確認の手順

1. Eclipseでバックエンドを起動する
2. `npm run dev`でフロントエンドを起動する
3. ブラウザで`http://localhost:5173`を開く
4. 「材料マスタ」画面が表示され、登録済みの材料(米粉など)が一覧に表示されれば成功
5. フォームから新しい材料を登録し、一覧に反映されるか確認する
